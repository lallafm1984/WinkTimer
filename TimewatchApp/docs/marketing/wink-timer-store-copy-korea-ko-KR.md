# Wink Timer 스토어 문구 - 대한민국

## 국가 정보

- 국가 이름: 대한민국
- 언어/로케일: 한국어 (ko-KR)
- 주요 검색어: 타이머, 알람, 알람시계, 스톱워치
- 보조 검색어: 반복 알람, 스누즈 알람, 요일 알람, 날짜 알람, 플립 타이머

## 앱 이름

```text
Wink Timer - 알람 타이머 스톱워치
```

## 간단한 설명

```text
알람·타이머·스톱워치, 손대지 않는 조작까지
```

## 전체 설명

```text
Wink Timer는 알람, 타이머, 스톱워치를 필요한 순간에 바로 꺼내 쓰는 일상용 시간 측정 앱입니다.

손이 바쁠 때도 시간은 멈추고, 이어가고, 기록할 수 있어야 합니다. 요리 중 손이 젖었거나 운동 중 화면을 누르기 어려울 때는 시선, 윙크, 기기 뒤집기로 타이머와 스톱워치를 조작하세요.

알람은 아침 기상, 수업, 회의, 운동 루틴, 휴식 종료처럼 다시 알려야 하는 순간에 맞춰 설정할 수 있습니다. 매일 반복, 요일 반복, 날짜 지정, 소리, 볼륨, 진동, 스누즈를 지원합니다.

타이머는 정해진 시간을 재야 할 때, 스톱워치는 경과 시간과 랩 기록이 필요할 때 빠르게 사용할 수 있습니다.

주요 기능

- 타이머: 버튼으로 빠르게 시작, 일시정지, 재개, 초기화
- 알람: 매일 반복, 요일 반복, 날짜 지정, 소리, 볼륨, 진동, 스누즈 설정
- 알람 관리: 여러 알람을 만들고 켜기, 끄기, 수정, 삭제
- 알람 울림 화면: 알람 정지 또는 스누즈 선택
- 스톱워치: 경과 시간 측정과 랩 기록
- 타이머 알림: 카운트다운 완료 시 소리와 진동 설정
- 손대지 않는 조작: 시선, 윙크, 기기 뒤집기로 상황에 맞게 시간 측정 제어
- LOOK PAUSE: 화면을 보는지에 따라 타이머 일시정지/재개
- WINK CONTROL: 윙크로 시작, 일시정지, 재개, 기록 조작
- FLIP TIMER: 기기를 뒤집어 시작하고 다시 올려 멈춤
- SMILE MODE: 미소 감지를 활용한 타이머 조작
- 기록 보기: 최근 측정 기록과 타임라인 확인

Wink Timer는 포커스 전용 앱이 아닙니다. 알람시계, 공부 타이머, 운동 타이머, 요리 타이머, 작업용 스톱워치처럼 다양한 상황에서 쓰는 일상용 시간 측정 앱입니다. 여기에 카메라와 센서 기반 조작을 더해 손을 쓰기 어려운 순간에도 시간을 다룰 수 있게 했습니다.

카메라 감지 기능은 기기 성능, 조명, 얼굴 각도, 카메라 위치에 따라 정확도가 달라질 수 있습니다.
```

## 앱 설치 캠페인 헤드라인

```text
알람·타이머·스톱워치
손대지 않고 시간 조작
반복 알람과 스누즈
윙크로 조작하는 스톱워치
뒤집어 쓰는 플립 타이머
```

## 앱 설치 캠페인 설명

```text
알람·타이머·스톱워치를 쓰고, 손대지 않는 시선·윙크·뒤집기 조작도 선택하세요.
매일 반복, 요일 반복, 날짜 알람을 만들고 소리·진동·스누즈를 설정하세요.
아침 기상, 수업, 운동, 휴식 알람부터 요리 타이머까지 한 앱에서 관리하세요.
카메라 없이도 알람·타이머·스톱워치를 바로 쓰고, 필요할 때 시선·윙크·뒤집기 조작을 켜세요.
타이머 완료 알림과 반복 알람을 소리, 볼륨, 진동 설정으로 맞춰 사용하세요.
```

## 알람 중심 광고 소재

### 헤드라인

```text
스누즈 되는 반복 알람
요일별 알람을 빠르게
날짜 알람까지 한 번에
소리·진동 알람 설정
알람과 타이머를 한 앱에
아침·운동·휴식 알람
```

### 설명

```text
아침 기상, 운동, 수업, 휴식 종료 알람을 매일·요일·날짜 반복으로 설정하세요.
소리, 볼륨, 진동, 스누즈를 고르고 알람을 켜고 끄며 일정을 관리하세요.
알람이 울리면 정지하거나 스누즈하고, 타이머와 스톱워치도 같은 앱에서 사용하세요.
```


## 문구 기준

- 앱을 포커스 전용 앱으로 표현하지 않습니다.
- 수익화 관련 표현을 사용하지 않습니다.
- 카메라 인식이 항상 완벽하다고 약속하지 않습니다.
- 알람이 모든 기기와 절전 설정에서 항상 정확히 울린다고 보장하지 않습니다.
- 타이머는 카메라 기능 없이 사용할 수 있는 일반 타이머로 표현합니다.
