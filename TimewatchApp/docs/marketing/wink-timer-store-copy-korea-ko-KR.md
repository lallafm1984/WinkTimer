# Wink Timer 스토어 문구 - 대한민국

## 국가 정보

- 국가 이름: 대한민국
- 언어/로케일: 한국어 (ko-KR)
- 주요 검색어: 타이머, 카운트다운 타이머, 스톱워치, 알람
- 보조 검색어: 노터치 타이머, 운동 타이머, 요리 타이머, 공부 타이머, 플립 타이머

## 앱 이름

```text
타이머 - 노터치 카운트다운
```

## 간단한 설명

```text
운동·요리·공부 중 손대지 않고 쓰는 타이머, 스톱워치, 알람
```

## 전체 설명

```text
타이머를 손대지 않고 더 편하게 사용하세요.

윙크 타이머는 카운트다운 타이머, 스톱워치, 알람을 한 곳에서 사용할 수 있는 시간 관리 앱입니다. 기본 타이머처럼 원하는 시간을 설정하고, 운동·요리·공부·업무 중에는 윙크, 시선, 미소, 휴대폰 뒤집기로 화면을 직접 누르지 않고 조작할 수 있습니다.

손이 젖었을 때, 장갑을 끼고 있을 때, 운동 자세를 유지해야 할 때, 집중을 깨고 싶지 않을 때 노터치 타이머로 시간을 관리해보세요.

주요 기능

카운트다운 타이머

- 원하는 시간으로 타이머 설정
- 시작, 일시정지, 다시 시작, 초기화 지원
- 타이머 종료 시 소리와 진동 알림
- 운동, 요리, 공부, 휴식, 반복 루틴에 활용

노터치 조작

- 윙크 모드: 윙크로 타이머 조작
- 시선 모드: 화면을 볼 때 타이머를 멈추고, 시선을 떼면 다시 시작
- 스마일 모드: 미소 인식으로 타이머 조작
- 뒤집기 모드: 휴대폰 방향으로 타이머 조작

스톱워치

- 경과 시간 측정
- 랩 기록 지원
- 운동, 공부, 테스트, 반복 작업 시간 측정

알람

- 기상 알람, 수업 알람, 회의 알람, 운동 알람, 휴식 알람 설정
- 매일 반복, 요일 반복, 날짜 알람 지원
- 알람 소리, 볼륨, 진동, 스누즈 설정
- 여러 개의 알람 생성, 수정, 켜기, 끄기, 삭제 가능

기록

- 최근 타이머와 스톱워치 기록 확인
- 자주 쓰는 시간 관리 흐름 확인

이럴 때 사용해보세요

- 운동 중 화면을 누르기 어려울 때
- 요리 중 손이 젖어 타이머 조작이 불편할 때
- 공부나 업무 중 집중을 깨지 않고 시간을 관리하고 싶을 때
- 스트레칭, 명상, 휴식, 루틴 시간을 관리할 때
- 스톱워치와 알람을 함께 쓰고 싶을 때
- 반복 작업 시간을 간단하게 측정하고 싶을 때

윙크 타이머는 기본 카운트다운 타이머에 윙크, 시선, 미소, 뒤집기 같은 노터치 조작을 더한 타이머, 스톱워치, 알람 앱입니다.

카메라 기반 노터치 기능은 기기 성능, 조명, 얼굴 각도, 카메라 위치에 따라 인식 결과가 달라질 수 있습니다.
```

## 문구 기준

- 앱을 포커스 전용 앱으로 표현하지 않습니다.
- BASIC TIMER가 기본 타이머 경험임을 유지합니다.
- 수익화 관련 표현을 사용하지 않습니다.
- 카메라 인식이 항상 완벽하다고 약속하지 않습니다.
- 알람이 모든 기기와 절전 설정에서 항상 정확히 울린다고 보장하지 않습니다.
- 타이머는 카메라 기능 없이 사용할 수 있는 일반 타이머로 표현합니다.
