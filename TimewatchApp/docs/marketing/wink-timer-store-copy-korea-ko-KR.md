# Wink Timer 스토어 문구 - 대한민국

## 국가 정보

- 국가 이름: 대한민국
- 언어/로케일: 한국어 (ko-KR)
- 주요 검색어: 타이머, 스톱워치

## 앱 이름

```text
Wink Timer - 타이머 스톱워치
```

## 간단한 설명

```text
타이머와 스톱워치에 시선·윙크·뒤집기 조작을 더한 시간 측정 앱
```

## 전체 설명

```text
Wink Timer는 타이머와 스톱워치를 빠르게 사용할 수 있는 시간 측정 앱입니다.

버튼으로 시작하고 멈추는 기본 타이머를 중심으로, 필요할 때 시선, 윙크, 기기 뒤집기 같은 조작 모드를 사용할 수 있습니다. 요리, 운동, 공부, 작업, 휴식 시간처럼 일상적인 타이머와 스톱워치가 필요한 순간에 가볍게 쓸 수 있습니다.

주요 기능

- 기본 타이머: 버튼으로 빠르게 시작, 일시정지, 재개, 초기화
- 스톱워치: 경과 시간 측정과 랩 기록
- 타이머 알림: 소리와 진동 설정
- LOOK PAUSE: 화면을 보는지에 따라 타이머 일시정지/재개
- WINK CONTROL: 윙크로 시작, 일시정지, 재개, 기록 조작
- FLIP TIMER: 기기를 뒤집어 시작하고 다시 올려 멈춤
- SMILE MODE: 미소 감지를 활용한 타이머 조작
- 기록 보기: 최근 측정 기록과 타임라인 확인

Wink Timer는 포커스 전용 앱이 아닙니다. 공부 타이머, 운동 타이머, 요리 타이머, 작업용 스톱워치처럼 다양한 상황에서 쓰는 일반 타이머 앱입니다. 여기에 카메라와 센서 기반 조작을 더해 손을 쓰기 어려운 순간에도 시간을 다룰 수 있게 했습니다.

카메라 감지 기능은 기기 성능, 조명, 얼굴 각도, 카메라 위치에 따라 정확도가 달라질 수 있습니다.
```

## 앱 설치 캠페인 헤드라인

```text
타이머와 스톱워치 한 번에
시선으로 멈추는 타이머
윙크로 조작하는 스톱워치
뒤집어 쓰는 플립 타이머
일상에 쓰는 스마트 타이머
```

## 앱 설치 캠페인 설명

```text
타이머와 스톱워치를 기본으로, 시선·윙크·뒤집기 조작까지 지원합니다.
요리, 운동, 공부, 작업 시간까지 빠르게 재고 기록하세요.
카메라 없이도 기본 타이머와 스톱워치를 바로 사용할 수 있습니다.
시선을 보면 멈추고, 윙크하면 조작하는 새로운 타이머 경험입니다.
버튼 조작부터 카메라·센서 조작까지 상황에 맞게 시간을 측정하세요.
```

## 스크린샷 문구

```text
타이머와 스톱워치 한 화면에서
기본 타이머는 버튼으로 빠르게
시선으로 멈추고 다시 이어가기
윙크로 기록하고 조작하기
기기를 뒤집어 시작하는 플립 타이머
```

## 문구 기준

- 앱을 포커스 전용 앱으로 표현하지 않습니다.
- 수익화 관련 표현을 사용하지 않습니다.
- 카메라 인식이 항상 완벽하다고 약속하지 않습니다.
- BASIC TIMER를 기본 타이머 경험으로 유지합니다.
