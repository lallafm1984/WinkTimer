```text
مؤقت وساعة إيقاف يمكن التحكم بهما بالكاميرا مع منبه.
```

## 전체 설명

```text
Wink Timer هو تطبيق يومي للمنبه والمؤقت وساعة الإيقاف.

عندما تكون يداك مشغولتين، يجب أن يبقى إيقاف الوقت مؤقتًا ومتابعته وتسجيله أمرًا سهلًا. أثناء الطبخ ويداك مبتلتان أو أثناء التمرين عندما يصعب لمس الشاشة، استخدم النظر أو الغمزة أو قلب الهاتف للتحكم بالمؤقت وساعة الإيقاف.

اضبط منبهات للاستيقاظ والدروس والاجتماعات والتمارين والاستراحات والروتين اليومي. تدعم المنبهات التكرار اليومي، أيام الأسبوع، التاريخ المحدد، الصوت، مستوى الصوت، الاهتزاز، والغفوة.

استخدم المؤقت عند الحاجة إلى عدّ مدة محددة. واستخدم ساعة الإيقاف لقياس الوقت المنقضي وتسجيل اللفات.

الميزات الرئيسية

- المؤقت: بدء، إيقاف مؤقت، متابعة، وإعادة ضبط بالأزرار
- المنبهات: تكرار يومي، أيام الأسبوع، تاريخ محدد، صوت، مستوى صوت، اهتزاز، وغفوة
- إدارة المنبهات: إنشاء عدة منبهات وتشغيلها وإيقافها وتعديلها وحذفها
- شاشة رنين المنبه: إيقاف المنبه أو اختيار الغفوة
- ساعة الإيقاف: قياس الوقت المنقضي وتسجيل اللفات
- تنبيهات المؤقت: صوت واهتزاز عند انتهاء العد التنازلي
- تحكم بدون لمس: النظر والغمزة وقلب الجهاز لإجراءات الوقت المدعومة
- LOOK PAUSE: إيقاف مؤقت ومتابعة حسب النظر إلى الشاشة
- WINK CONTROL: استخدام الغمزة لإجراءات المؤقت وتسجيل اللفات
- FLIP TIMER: اقلب الهاتف لأسفل للبدء ولأعلى للإيقاف المؤقت
- SMILE MODE: التحكم في المؤقت عبر اكتشاف الابتسامة
- السجل: مراجعة قياسات الوقت الحديثة وأحداث الخط الزمني

Wink Timer ليس تطبيقًا مخصصًا للتركيز أو الدراسة فقط. استخدمه كساعة منبه، مؤقت للطبخ، مؤقت للتمرين، مؤقت للدراسة، مؤقت للعمل، مؤقت للاستراحة، أو ساعة إيقاف سريعة.

قد تختلف ميزات الكاميرا حسب أداء الجهاز والإضاءة وزاوية الوجه وموضع الكاميرا.
```

```text

عندما تكون يداك مبتلتين أو أثناء التمرين، تحكم بالمؤقت بدون لمس الشاشة.
اختر الإيقاف بالنظر أو التحكم بالغمزة أو الابتسامة أو مؤقت قلب الهاتف.
أثناء الطبخ أو التمرين أو الدراسة أو العمل، تابع المؤقت بسهولة أكبر.
استخدم التعرف عبر الكاميرا للبدء والإيقاف المؤقت والمتابعة والتسجيل بلمسات أقل.
```
