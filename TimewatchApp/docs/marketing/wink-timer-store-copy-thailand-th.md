# Wink Timer 스토어 문구 - 태국

## 국가 정보

- 국가 이름: 태국
- 앱 내부 로케일: 태국어/태국 (th-TH)
- Google Play 스토어 로케일: 태국어 (th)
- 주요 검색어: ตัวจับเวลา, นาฬิกาจับเวลา

## 앱 이름

```text
Wink Timer: ตัวจับเวลา
```

## 간단한 설명

```text
ตัวจับเวลาและนาฬิกาจับเวลาพร้อมควบคุมด้วยสายตา ขยิบตา พลิกเครื่อง และยิ้ม
```

## 전체 설명

```text
Wink Timer คือแอปตัวจับเวลาและนาฬิกาจับเวลาสำหรับการวัดเวลาในชีวิตประจำวัน

เริ่มใช้เป็นตัวจับเวลาแบบปุ่มทั่วไปก่อน คุณสามารถเริ่ม หยุดชั่วคราว ทำต่อ รีเซ็ต ตั้งการแจ้งเตือน และบันทึกรอบของนาฬิกาจับเวลาได้อย่างรวดเร็ว

เมื่อต้องการควบคุมที่ยืดหยุ่นขึ้น ให้เปลี่ยนไปใช้โหมดช่วยเหลือที่ใช้สายตา การขยิบตา การพลิกโทรศัพท์ หรือรอยยิ้ม

ฟีเจอร์หลัก

- ตัวจับเวลาพื้นฐาน: เริ่ม หยุดชั่วคราว ทำต่อ และรีเซ็ตด้วยปุ่ม
- นาฬิกาจับเวลา: วัดเวลาที่ผ่านไปและบันทึกรอบ
- การแจ้งเตือนตัวจับเวลา: ตั้งค่าเสียงและการสั่น
- LOOK PAUSE: หยุดชั่วคราวและทำต่อตามการมองหน้าจอ
- WINK CONTROL: ใช้การขยิบตาเพื่อควบคุมตัวจับเวลาและบันทึกรอบ
- FLIP TIMER: พลิกโทรศัพท์คว่ำเพื่อเริ่ม และหงายขึ้นเพื่อหยุดชั่วคราว
- SMILE MODE: ควบคุมตัวจับเวลาด้วยการตรวจจับรอยยิ้ม
- ประวัติ: ดูบันทึกเวลาล่าสุดและเหตุการณ์ในไทม์ไลน์

Wink Timer ไม่ได้จำกัดเฉพาะการโฟกัสหรือการเรียน ใช้เป็นตัวจับเวลาทำอาหาร ออกกำลังกาย เรียน ทำงาน พัก หรือเป็นนาฬิกาจับเวลาเร็วสำหรับกิจวัตรประจำวันได้

ตัวจับเวลาและนาฬิกาจับเวลาพื้นฐานใช้งานง่าย ส่วนโหมดที่ใช้กล้องและเซ็นเซอร์ช่วยเมื่อไม่สะดวกแตะหน้าจอ

ฟีเจอร์ที่ใช้กล้องอาจแตกต่างกันตามประสิทธิภาพอุปกรณ์ แสง มุมใบหน้า และตำแหน่งกล้อง
```

## 앱 설치 캠페인 헤드라인

```text
จับเวลาและนาฬิกาจับเวลา
ขยิบตาควบคุมตัวจับเวลา
นาฬิกาจับเวลาด้วยท่าทาง
พลิกโทรศัพท์เพื่อเริ่ม
ตัวจับเวลาใช้ได้ทุกวัน
```

## 앱 설치 캠페인 설명

```text
ใช้ตัวจับเวลาและนาฬิกาจับเวลาด้วยสายตา ขยิบตา พลิกเครื่อง และยิ้ม
วัดเวลาทำอาหาร ออกกำลังกาย เรียน ทำงาน พัก และรอบเร็ว
ใช้ตัวจับเวลาและนาฬิกาจับเวลาพื้นฐานได้โดยไม่ต้องเปิดกล้อง
มองหน้าจอ ขยิบตา หรือพลิกโทรศัพท์เพื่อควบคุมเวลา
บันทึกรอบ การแจ้งเตือน และประวัติล่าสุดในแอปเดียว
```
