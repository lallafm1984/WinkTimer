## 전체 설명

```text
Gunakan timer dengan lebih nyaman tanpa menyentuh layar.

Wink Timer adalah aplikasi waktu dengan timer hitung mundur, stopwatch, dan alarm dalam satu tempat. Atur waktu seperti timer biasa, lalu saat olahraga, memasak, belajar, atau bekerja, kendalikan timer dengan kedipan, pandangan, senyum, atau membalik ponsel tanpa menyentuh layar.

Saat tangan basah, memakai sarung tangan, mempertahankan posisi latihan, atau tidak ingin kehilangan fokus, gunakan timer tanpa sentuh untuk mengatur waktu.

Fitur utama

Timer hitung mundur

- Atur durasi timer sesuai kebutuhan
- Mulai, jeda, lanjutkan, dan reset
- Suara dan getar saat timer selesai
- Cocok untuk olahraga, memasak, belajar, istirahat, dan rutinitas

Kontrol tanpa sentuh

- Mode kedip: kendalikan timer dengan kedipan
- Mode pandangan: timer berhenti saat Anda melihat layar, lalu berjalan lagi saat pandangan dialihkan
- Mode senyum: kendalikan timer dengan deteksi senyum
- Mode balik: kendalikan timer dengan posisi ponsel

Stopwatch

- Ukur waktu berjalan
- Catat lap
- Cocok untuk olahraga, belajar, tes, dan pekerjaan berulang

Alarm

- Atur alarm bangun, kelas, rapat, olahraga, dan istirahat
- Pengulangan harian, hari tertentu, dan alarm tanggal
- Atur suara alarm, volume, getar, dan snooze
- Buat, edit, aktifkan, nonaktifkan, dan hapus beberapa alarm

Riwayat

- Lihat catatan timer dan stopwatch terbaru
- Periksa alur pengaturan waktu yang sering Anda gunakan

Gunakan saat:

- Sulit menyentuh layar saat olahraga
- Tangan basah saat memasak
- Ingin mengatur waktu belajar atau kerja tanpa memecah fokus
- Mengatur waktu peregangan, meditasi, istirahat, atau rutinitas
- Ingin memakai stopwatch dan alarm dalam satu aplikasi
- Perlu mengukur pekerjaan berulang dengan cepat

Wink Timer menambahkan kontrol kedip, pandangan, senyum, dan balik ponsel ke timer hitung mundur, stopwatch, dan alarm dasar.

Fitur tanpa sentuh berbasis kamera dapat berbeda hasilnya tergantung performa perangkat, pencahayaan, sudut wajah, dan posisi kamera.
```
