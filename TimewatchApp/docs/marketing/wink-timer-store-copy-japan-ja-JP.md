
## 전체 설명

```text
Wink Timerは、毎日の時間計測に使えるタイマー・ストップウォッチアプリです。

まずは通常のボタン操作で使える基本タイマーとして、開始、一時停止、再開、リセット、タイマー通知、ストップウォッチのラップ記録をすばやく使えます。

必要なときは、視線、ウィンク、端末の反転、笑顔を使った補助操作モードに切り替えられます。

主な機能

- 基本タイマー: ボタンで開始、一時停止、再開、リセット
- ストップウォッチ: 経過時間の計測とラップ記録
- タイマー通知: 音とバイブレーションを設定
- LOOK PAUSE: 画面を見ているかどうかで一時停止・再開
- WINK CONTROL: ウィンクでタイマー操作やラップ記録
- FLIP TIMER: 端末を伏せて開始し、表に戻して一時停止
- SMILE MODE: 笑顔検出を使ったタイマー操作
- 履歴: 最近の計測記録とタイムラインを確認

Wink Timerは集中や勉強だけのアプリではありません。料理タイマー、運動タイマー、勉強タイマー、作業タイマー、休憩タイマー、日常のストップウォッチとして幅広く使えます。

基本のタイマーとストップウォッチはシンプルに使え、カメラやセンサーを使う補助モードは、画面に触れにくい場面で時間を操作しやすくします。

カメラを使う機能は、端末性能、明るさ、顔の角度、カメラ位置によって認識精度が変わる場合があります。
```

## 앱 설치 캠페인 헤드라인

```text
タイマーとストップウォッチ
視線で止めるタイマー
ウィンクで操作する計測
裏返して始めるタイマー
毎日に使えるスマートタイマー
```

## 앱 설치 캠페인 설명

```text
タイマーとストップウォッチに、視線・ウィンク・反転・笑顔の操作を追加。
料理、運動、勉強、作業、休憩の時間をすばやく計測して記録できます。
カメラなしでも基本のタイマーとストップウォッチをすぐに使えます。
画面を見る、ウィンクする、端末を裏返す操作で時間をコントロール。
ボタン操作からカメラ・センサー補助まで、場面に合わせて時間を測れます。
```

## 스크린샷 문구

```text
タイマーとストップウォッチを1つに
基本タイマーはボタンで簡単操作
視線で一時停止と再開
ウィンクで記録と操作
端末を裏返してスタート
```
