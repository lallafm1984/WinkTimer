```text
カメラで操作できるタイマー・ストップウォッチとアラーム。
```

## 전체 설명

```text
Wink Timerは、アラーム、タイマー、ストップウォッチを必要なときにすぐ使える日常向けの時間管理アプリです。

手がふさがっていても、時間の一時停止、再開、記録はスムーズに行いたいものです。料理中で手が濡れているときや、運動中で画面を押しにくいときは、視線、ウィンク、端末の反転でタイマーやストップウォッチを操作できます。

アラームは起床、授業、会議、運動、休憩、毎日のルーティンに合わせて設定できます。毎日、曜日、日付指定、サウンド、音量、バイブレーション、スヌーズに対応しています。

決まった時間を測るときはタイマーを、経過時間やラップを記録したいときはストップウォッチを使えます。

主な機能

- タイマー: ボタンで開始、一時停止、再開、リセット
- アラーム: 毎日、曜日、日付指定、サウンド、音量、バイブレーション、スヌーズ
- アラーム管理: 複数のアラームを作成、オン、オフ、編集、削除
- アラーム鳴動画面: アラーム停止またはスヌーズを選択
- ストップウォッチ: 経過時間の計測とラップ記録
- タイマー通知: カウントダウン終了時の音とバイブレーション
- 触れずに操作: 視線、ウィンク、端末の反転で対応する時間操作を実行
- LOOK PAUSE: 画面を見ているかどうかで一時停止・再開
- WINK CONTROL: ウィンクでタイマー操作やラップ記録
- FLIP TIMER: 端末を伏せて開始し、表に戻して一時停止
- SMILE MODE: 笑顔検出を使ったタイマー操作
- 履歴: 最近の計測記録とタイムラインを確認

Wink Timerは集中や勉強だけのアプリではありません。目覚まし、料理タイマー、運動タイマー、勉強タイマー、作業タイマー、休憩タイマー、日常のストップウォッチとして使えます。

カメラを使う機能は、端末性能、明るさ、顔の角度、カメラ位置によって認識精度が変わる場合があります。
```

```text
触れずに時間を操作
繰り返しアラームとスヌーズ
ウィンクでラップ記録
裏返してタイマー開始
```

## 앱 설치 캠페인 설명

```text
視線、ウィンク、笑顔でタイマーを操作し、ウィンクでストップウォッチのラップも記録。
手が濡れている時や運動中でも、画面に触れずにタイマーを操作できます。
視線で一時停止、ウィンク操作、笑顔操作、反転タイマーを場面に合わせて選択。
料理、運動、勉強、作業中でもタイマーをスムーズに続けられます。
カメラ認識で開始、一時停止、再開、記録をより手軽に操作できます。
```
