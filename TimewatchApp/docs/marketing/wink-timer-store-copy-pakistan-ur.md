# Wink Timer 스토어 문구 - 파키스탄

## 국가 정보

- 국가 이름: 파키스탄
- 앱 내부 로케일: 우르두어/파키스탄 (ur-PK)
- Google Play 스토어 로케일: 우르두어 (ur)
- 주요 검색어: ٹائمر, اسٹاپ واچ

## 앱 이름

```text
Wink Timer: ٹائمر اسٹاپ واچ
```

## 간단한 설명

```text
نظر، آنکھ جھپکانے، فون پلٹنے اور مسکراہٹ سے چلنے والا ٹائمر اور اسٹاپ واچ۔
```

## 전체 설명

```text
Wink Timer روزمرہ وقت ناپنے کے لیے ٹائمر اور اسٹاپ واچ ایپ ہے۔

اسے پہلے ایک عام بٹن والے ٹائمر کی طرح استعمال کریں۔ جب وقت جلدی ناپنا ہو تو شروع کریں، روکیں، دوبارہ چلائیں، ری سیٹ کریں، ٹائمر الرٹ لگائیں اور اسٹاپ واچ لیپس ریکارڈ کریں۔

جب آپ کو زیادہ لچکدار کنٹرول چاہیے ہو تو ایسے معاون موڈز استعمال کریں جو نظر، آنکھ جھپکانے، فون پلٹنے یا مسکراہٹ سے وقت کنٹرول کرنے میں مدد دیتے ہیں۔

اہم خصوصیات

- Basic Timer: بٹن سے شروع، pause، resume اور reset
- اسٹاپ واچ: گزرا ہوا وقت ناپیں اور لیپس ریکارڈ کریں
- ٹائمر الرٹس: آواز اور وائبریشن سیٹ کریں
- LOOK PAUSE: اسکرین دیکھنے کی بنیاد پر pause اور resume
- WINK CONTROL: ٹائمر ایکشنز اور لیپس کے لیے آنکھ جھپکانے کے اشارے
- FLIP TIMER: شروع کرنے کے لیے فون کو نیچے کی طرف پلٹیں، روکنے کے لیے اوپر کریں
- SMILE MODE: مسکراہٹ کی شناخت سے ٹائمر کنٹرول
- ہسٹری: حالیہ ریکارڈز اور ٹائم لائن ایونٹس دیکھیں

Wink Timer صرف فوکس یا پڑھائی کے لیے نہیں ہے۔ اسے cooking timer، workout timer، study timer، work timer، break timer یا روزمرہ کی تیز اسٹاپ واچ کے طور پر استعمال کریں۔

Basic Timer اور اسٹاپ واچ استعمال میں آسان ہیں، جبکہ camera اور sensor-assisted modes اس وقت مدد دیتے ہیں جب اسکرین کو چھونا آسان نہ ہو۔

Camera-based features ڈیوائس performance، روشنی، چہرے کے زاویے اور camera position کے مطابق بدل سکتے ہیں۔
```


## 앱 설치 캠페인 설명

```text
نظر، آنکھ جھپکانے، فون پلٹنے اور مسکراہٹ سے ٹائمر اور اسٹاپ واچ چلائیں۔
کھانا، ورزش، پڑھائی، کام، وقفہ اور تیز لیپس ریکارڈ کریں۔
Basic Timer اور اسٹاپ واچ camera آن کیے بغیر بھی استعمال کریں۔
اسکرین دیکھیں، آنکھ جھپکائیں یا فون پلٹ کر وقت کنٹرول کریں۔
لیپس، ٹائمر الرٹس اور حالیہ ریکارڈز ایک آسان ایپ میں رکھیں۔
```

## 문구 기준

- 앱을 포커스 전용 앱으로 표현하지 않습니다.
- 수익화 관련 표현을 사용하지 않습니다.
- 카메라 인식이 항상 완벽하다고 약속하지 않습니다.
- BASIC TIMER를 기본 타이머 경험으로 유지합니다.
