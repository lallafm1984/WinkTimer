# Wink Timer Store And Campaign Copy (KO)

## Purpose

This document collects Korean copy for the Wink Timer Google Play store listing and app install campaign assets.

The copy should prioritize discoverability for these search terms:

- 타이머
- 스톱워치

The user-facing copy should not mention monetization mechanics. Wink Timer should be positioned as a general-purpose timer and stopwatch app, not as a focus-only app.

## Core Positioning

Wink Timer is a timer and stopwatch app for everyday timing. It starts with normal button-based timing, then adds optional gesture-style controls such as looking, winking, flipping the device, and smiling.

Primary message:

```text
타이머와 스톱워치에 시선·윙크·뒤집기 조작을 더한 시간 측정 앱
```

### Full Description

```text
Wink Timer는 타이머와 스톱워치를 빠르게 사용할 수 있는 시간 측정 앱입니다.

버튼으로 시작하고 멈추는 기본 타이머를 중심으로, 필요할 때 시선, 윙크, 기기 뒤집기 같은 조작 모드를 사용할 수 있습니다. 요리, 운동, 공부, 작업, 휴식 시간처럼 일상적인 타이머와 스톱워치가 필요한 순간에 가볍게 쓸 수 있습니다.

주요 기능

- 기본 타이머: 버튼으로 빠르게 시작, 일시정지, 재개, 초기화
- 스톱워치: 경과 시간 측정과 랩 기록
- 타이머 알림: 소리와 진동 설정
- LOOK PAUSE: 화면을 보는지에 따라 타이머 일시정지/재개
- WINK CONTROL: 윙크로 시작, 일시정지, 재개, 기록 조작
- FLIP TIMER: 기기를 뒤집어 시작하고 다시 올려 멈춤
- SMILE MODE: 미소 감지를 활용한 타이머 조작
- 기록 보기: 최근 측정 기록과 타임라인 확인

Wink Timer는 포커스 전용 앱이 아닙니다. 공부 타이머, 운동 타이머, 요리 타이머, 작업용 스톱워치처럼 다양한 상황에서 쓰는 일반 타이머 앱입니다. 여기에 카메라와 센서 기반 조작을 더해 손을 쓰기 어려운 순간에도 시간을 다룰 수 있게 했습니다.

카메라 감지 기능은 기기 성능, 조명, 얼굴 각도, 카메라 위치에 따라 정확도가 달라질 수 있습니다.
```

## Copy Guardrails

- Use 타이머 and 스톱워치 naturally in high-visibility fields.
- Do not describe Wink Timer as only a focus, study, or concentration app.
- Do not promise perfect camera recognition.
- Do not mention monetization mechanics in user-facing copy.
- Keep BASIC TIMER framed as the baseline timer experience.
